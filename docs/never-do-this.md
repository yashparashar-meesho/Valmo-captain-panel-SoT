# Never do this

Every line here cost someone real time at least once. Each says what not to do
and **what actually happens** if you do it, because a rule without a consequence
gets ignored.

---

## Editing the wrong file

| never | because |
|---|---|
| Edit `assets/kit.css` | It is generated. The next export silently overwrites your change and you lose it without an error. Edit the `<style>` block in `source/flow-ledger.html`. |
| Edit `index.html`, `screens/*.html`, `components/*.html` | All generated by `scripts/export_to_github.py`. Same silent overwrite. The source is `source/flow-ledger.html` + `source/data-seed.json`. |
| Edit `docs/pages.md` or `docs/components.md` | Generated by `scripts/build_docs.py` from the catalogue. |
| Write `source/data-seed.json` without updating the copy embedded in `flow-ledger.html` | They must be written together. When they drifted once, three icons silently reverted and nobody noticed until the pages were opened. `check_v2_sync.py` now fails on it. |

## Markup and CSS

| never | because |
|---|---|
| Put a `<script>` inside a screen's `code` | The literal `</script>` closes the seed element early. The JSON then fails to parse with an error that points nowhere near the cause. Vendor the behaviour under `source/assets/vendor/` and let `VENDOR_RULES` pull it in. |
| Add `font-weight: 500` | Mier B02 has no 500 face. It silently resolves to 400 Book — measured identical, to the hundredth of a pixel. You have written a rule that does nothing while believing you changed something. |
| Use `line-height: normal` | It depends on the font file. If Mier ever falls back to the metric-matched stand-in, every control using it changes height. Always set an explicit line-height. |
| Use `overflow: auto` for a scroll area | The scrollbar appears and disappears, shifting layout by its own width, and users cannot tell the area scrolls. Use `scroll`, per [layout-rules.md](layout-rules.md). |
| Give a component its own copy of the kit | That duplication was once 62% of the file. The kit lives once. |
| Add a third section to a page | No screen has three. See [section-rules.md](section-rules.md) — it is almost always two pages or a misread card. |

## Measuring against live

| never | because |
|---|---|
| Read sizes, borders or fills off a screenshot | At the scale the tools return, a 1px `#E6EBF2` border is invisible and `#F2F5FA` on white is a 4% step. One outlined card holding two rows read as two grey tiles. Screenshots tell you *something is wrong*, never *what it should be*. |
| Match an element by text without scoping past the rail | The rail repeats module names. `leaf('Pilot Rate Card')` matched the **nav item**, not the card header, and shipped the wrong type size. Filter on `getBoundingClientRect().left > 250` and assert exactly one match. |
| Assume a control is the same everywhere | Check a second module before changing a shared component. The language button is on DC Capacity *and* eight times on Growth Dashboard. |
| Round live to the nearest token without saying so | Fine to deviate — four DC Capacity values deliberately do. Not fine to deviate quietly. Write it in a comment and in [fidelity-checklist.md](fidelity-checklist.md), or the next person "fixes" it. |

## On the live panel

| never | because |
|---|---|
| Click **Save Delivery & Pickup Capacity** | Writes real capacity for a real DC. Read-only measurement always; type into fields to see states, never submit. |
| Click **View Details** on Growth Dashboard | Explicitly out of scope — that page is not being rebuilt. |
| Click **Download AWB Details** | UI only. |

When in doubt on live: reading the DOM and typing into inputs is safe.
Anything that submits is not.

## Git and process

| never | because |
|---|---|
| `git commit --no-verify` | Skips TruffleHog. The repo is **public** — a leaked key is public immediately. |
| `git add -A` without checking | `.claude/` and `scripts/collect_elements.py` are untracked on purpose and are not in `.gitignore`. |
| Ship a module in the same PR as its new components | Components first, separately. A module PR that depends on components not yet upstream cannot be reviewed on its own. |
| Push explorations to `main` | Losing wireframes go to the Idea Wall or a branch that is never merged. The catalogue is the source of truth; the wall is a photo of an idea. |
| Let Figma become the source | Figma is the gallery. Screenshots cannot be diffed, measured or promoted from. HTML stays the artifact. |

## Working style

| never | because |
|---|---|
| Re-upload or re-publish while still iterating | Every approval prompt spends the user's attention. Verify locally first, publish once. |
| Report a step as done without running it | A script that logged six successful edits had written nothing — a later assertion threw before the file was saved. Persist after each step, and verify the artefact, not the log. |
| Invent a count ("5 approaches", "3 options") | Fixed counts manufacture filler. Say how many are genuinely distinct, even when that is two. |

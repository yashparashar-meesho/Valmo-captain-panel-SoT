# A worked run — Capacity Cut for Latent

The artefacts from one real pass of the design method, kept as they were
produced rather than tidied afterwards. They are what the `slipstream` skill
hands over at each stage.

| file | the stage it came from |
|---|---|
| `BRIEF.md` | Section 0 — the problem, pinned down. Constraints `C1`–`C8`, success tests `T1`–`T4`, situations `S1`–`S7`. |
| `APPROACHES.md` | Section 1 — the DRD. Five approaches on the axes, each with the captain's journey and the case for it. |
| `shapes.html` | Section 2 — all five drawn as schematics, every shape marked against every situation. |

**Read them in that order.** Each one is checked against the one before it,
which is the point: an approach that contradicts the brief is caught because
the brief was written down first.

The numbers are real. This was an actual KRD, not an invented example.

Rendered for reading at [`pack/run/`](../../pack/run/index.html).
